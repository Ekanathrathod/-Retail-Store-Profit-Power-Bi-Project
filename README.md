# Retail-Store-Profit-Power-Bi-Project
Developed an interactive Power BI dashboard to analyze the performance of various product categories in a retail store.

✅ Analyzed sales and profit data to identify top and underperforming product categories.
✅ Discovered that Clothing was the highest revenue-generating category (₹13,325 / 36.65%), while Furniture had the lowest profit (₹10,476 / 28.34%).
✅ Identified seasonal demand spikes in November, supporting data-driven decisions for inventory and promotional planning.
✅ Used slicers, KPI cards, and bar/line charts for dynamic filtering and performance tracking.

The dashboard enabled business users to make faster, data-backed decisions on sales strategies and category optimization.
